## Installation

To use this package simply reference it from your .NET project, which will download the specified
version from the [nuget.org](https://www.nuget.org/packages/OwlDomain.{project}) source.

In a C# project (a .csproj file) that would look like this:

```xml
<ItemGroup>
	<PackageReference Include="OwlDomain.{project}" Version="1.0.0" />
</ItemGroup>
```
